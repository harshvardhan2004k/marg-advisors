# Marg Advisors Static Website Starter

This workspace is a simple read-only website starter for a mutual fund advisory business. It uses only static files, so it can be hosted for free.

## What is included

- Home page
- About page
- Services page
- FAQ page
- Contact page
- Shared CSS and a small mobile menu script

## How to use it

1. Open `index.html` in your browser.
2. Replace the placeholder business details, including ARN or SEBI registration only if applicable.
3. Add the real office address, business hours, and contact details.
4. Publish the folder to a free static host.

## Publish with GitHub Pages

1. Create a new GitHub repository for this folder.
2. Push the files to the `main` branch.
3. In the repository settings, open `Pages`.
4. Set the source to `GitHub Actions`.
5. Push again or run the `Deploy to GitHub Pages` workflow manually.
6. After the workflow completes, GitHub will show the live site URL.

## Free hosting options

- GitHub Pages
- Netlify
- Cloudflare Pages

## Notes for GitHub Pages

- The workflow in `.github/workflows/pages.yml` deploys the static files automatically.
- The `.nojekyll` file keeps GitHub Pages from ignoring folders or files that do not need Jekyll processing.

## Notes

- No backend is required.
- No database is required.
- The site is read-only and can stay completely free.
- Mutual fund investments are subject to market risk.
